# Eko: The Lagoon Years: downloads

This repository only hosts the downloadable builds of **Eko: The Lagoon Years**, a historical adventure set in Lagos (Eko), 1851–1861, by [Tens Games](https://tens.games) (Tensflare Ltd).

**Get the game at [tens.games/eko](https://tens.games/eko/)**, or from the [latest release](../../releases/latest).

These are **early-development builds**: unsigned, unfinished, and changing often. Dialogue is placeholder English awaiting a language pass, voices and music are partly AI-generated placeholders, and you may meet bugs. Read the notes on the release page before installing.
